# FormFlow — Student Form Generator

Open `index.html` in a browser. Keep `index.html` and `name.xlsx` in the same folder.

Features:
- Loads `name.xlsx` automatically as sample data.
- Uploads XLSX/XLS/CSV files.
- Generates a colourful form for every row.
- Edits are reflected in downloads.
- Downloads one form or all forms as PDF.
- No "Form X of Y" text is included.

The app uses SheetJS and jsPDF from jsDelivr, so an internet connection is needed.
